## 🚀 Things I've built

### 🔬 ResearchPilot

**Multi-Agent RAG Research Assistance System**

A research assistant that takes a natural-language research question and turns it into an evidence-grounded technical report.

Built around:

`LangGraph` `LangChain` `RAG` `FAISS` `Sentence Transformers` `FastAPI` `Ollama`

The fun part?

It isn't just one LLM call pretending to be an architecture.

It uses multiple specialized agents for things like:

**Query → Expansion → Retrieval → Verification → Acquisition → Compression → Evidence Extraction → Reasoning**

Basically, I gave an AI a research assignment and then gave it several AI coworkers.
